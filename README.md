# Trilho — Pix → USDT (TRC-20)

Site estatico (HTML + CSS + JS puro, sem build) para intermediacao de compra de USDT com pagamento via Pix, voltado a quem paga fornecedores no exterior.

## Estrutura
- `index.html` — pagina unica, semantica, com JSON-LD `FinancialService`
- `assets/trilho.css` — tokens, tema claro/escuro, responsivo 320px–1920px
- `assets/trilho.js` — simulador de cotacao, tema, menu, validacao, LGPD

## Pendencias antes de publicar
- Razao social, CNPJ, situacao de autorizacao no BCB
- Tarifa de intermediacao real (hoje `[TAXA A DEFINIR]`)
- Canais de SAC e ouvidoria
- Destino do formulario (WhatsApp, CRM, e-mail)
- Paginas de Privacidade, Termos e Cookies
- Cotacao vinda do provedor de liquidez, nao de referencia publica

> Este conteudo nao substitui revisao juridica e de compliance.
